# Webpack Documentation Working Group

A working group within the webpack organization, responsible for the webpack documentation site and the wider documentation experience across the organization's projects.

---

## Working Group Name

Webpack Documentation Working Group (`docs-wg`)

## Purpose and Responsibilities

The Documentation Working Group owns the content, structure, and tooling behind webpack's documentation. Our mission is to make webpack approachable for newcomers and precise for advanced users, so that the docs stay accurate as the toolchain evolves.

Members are responsible for:

- Maintaining [webpack.js.org](https://github.com/webpack/webpack.js.org) — content, site infrastructure, and build tooling.
- Reviewing and merging documentation pull requests, and triaging documentation issues.
- Keeping documentation in sync with releases, including migration guides and changelog-driven updates.
- Defining and upholding style, terminology, and structure conventions for webpack docs.
- Supporting and mentoring first-time contributors, since docs are a common entry point into the project.
- Coordinating with the webpack TSC and other working groups when documentation changes follow from technical decisions.

Membership is expected to be active: members participate in reviews and discussions, and are welcome to step back at any time.

## Goals & Objectives

- Keep reference documentation (configuration, loaders, plugins, APIs) complete and current with the latest release line.
- Improve the getting-started and guides sections so a new user can go from install to a working build without leaving the docs.
- Reduce documentation issue and pull request response time, and keep the backlog manageable.
- Establish a written style guide and contribution guide for documentation changes.
- Improve accessibility, internationalization, and search on the documentation site.
- Grow the pool of regular documentation contributors and reviewers.
